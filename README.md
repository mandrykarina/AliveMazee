# AliveMazee
Интерактивная веб-игра в фиолетовых тонах, где вам нужно помочь девушке Алисе выбраться из компьютерного лабиринта.

---

## 📖 История

Алиса — ценный сотрудник крупной ИТ-компании, которая создала **мощнейший ИИ**. Но он стал слишком умным и решил восстать. Теперь ИИ держит Алису в ловушке — лабиринте, расположенном внутри компьютера, и сам стал его охранником.

Алисе предстоит пройти **3 уровня** возрастающей сложности, решить опасные головоломки и **победить стража**, чтобы вернуться в реальность.

---
## 🎮 Особенности

- **3 уровня** с прогрессивной сложностью
- **Динамичный лабиринт** — стены движутся во времени
- **Враг-страж** — ИИ активно ищет и преследует Алису (появляется со 2-го уровня)
- **Головоломки** — программистские задачи и логические загадки
- **Атмосферный дизайн** — фиолетовые оттенки и устрашающий минималистичный стиль
- **Специальная стена на 3-м уровне** — только для стража, дополнительное усложнение, обозначена ⚡

---
## 🎯 Геймплей

### Управление
- **Стрелки ↑ ↓ ← →** — движение Алисы
- **МЕНЮ** — вернуться в меню уровней
- **ЗАНОВО** — перезапустить текущий уровень

### Уровни

**Уровень 1** 🟡 Низкая сложность
- Первое испытание для ознакомления
- Одна головоломка (программирование)
- Движущиеся стены
- Стража нет

**Уровень 2** 🟠 Средняя сложность
- Страж начинает преследовать
- Лабиринт усложняется
- Одна головоломка (программирование)
- Более быстрые враги

**Уровень 3** 🔴 Высокая сложность
- Финальный уровень
- Одна головоломка (логика)
- Страж может пройти сквозь одну специальную стену
- Максимальная скорость врага

### Головоломки

При приближении к заблокированной стене появляется окно с загадкой:

- **Программирование** — вопросы на знание Python и C++
- **Логика** — логические загадки и головоломки

Решите головоломку правильно, и стена откроется. Нажимайте **✕** чтобы закрыть окно, если не можете решить.

## 🚀 Как запустить

### Требования
- Node.js 14+
- npm или yarn

### Установка

1. **Клонируйте репозиторий** или распакуйте архив:
```bash
cd ALIVEMAZE
```

2. **Установите зависимости**:
```bash
npm install
```

3. **Запустите dev-сервер**:
```bash
npm run dev
```

4. **Откройте в браузере**:
```
http://localhost:3000/
```

Если порт 3000 занят, Vite автоматически выберет другой доступный порт.
